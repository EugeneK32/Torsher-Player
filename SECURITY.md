# Security Policy

Torsher Player opens local files and remote media URLs and can send playback progress to a caller-provided callback endpoint. Treat URLs, headers and callback endpoints as untrusted input.

For a security issue, please avoid posting exploit details in a public issue until a maintainer has had a chance to assess it. Use GitHub's private vulnerability reporting feature when it is enabled for the repository.

Only the latest release line is intended to receive security fixes.
